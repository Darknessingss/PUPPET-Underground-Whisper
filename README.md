# PUPPET: Шёпот Подземного Города

**Top-down хоррор-экшен с Souls-like циклом, ритмом пульса и светом как ресурсом.**
Unity 6000.5.8f1 · URP 2D Renderer · C# · Windows.

> Мир сгнил. Инфекция «Пыль» превратила людей в Монстров. Спасения не было.
> Тогда группа выживших нашла выход: перенести душу и органы в кукол.
> Ты — Ек. Ты очнулся в подземном городе, в мастерской, среди сотен пустых тел.

## Что это

Играбельный вертикальный срез по ТЗ: шесть связанных зон, три оружия,
четыре типа врагов и босс, система Души, ритмическая пульс-механика,
свет/тьма, медитация у синих фонарей, три тела-класса, осколки памяти,
сохранение, HUD, журнал, карта и финальная сцена.

## Как запустить

1. Откройте папку `Build`.
2. Запустите `PUPPET_UndergroundWhisper.exe`.
3. Или запустите `Start_PUPPET.bat` из корня проекта.

В Unity стартовая сцена — `Assets/PUPPET/Scenes/MainMenu.unity` (индекс 0 в Build Settings).
Меню редактора: `PUPPET → Open Main Menu Scene`. Не запускайте `GameScene` из старой папки `!MyProject` — это чужой прототип без меню PUPPET.

Сохранение: `%USERPROFILE%\AppData\LocalLow\Darknessings\PUPPET_ Шёпот Подземного Города\puppet_save.json`.

Патроны: в магазине и в запасе. Подбор патронов пополняет **запас**, перезарядка тратит запас. В HUD отображается `7 / 8` и `ЗАПАС 8`.

## Управление

| Действие | Клавиша |
|---|---|
| Движение | WASD / стрелки |
| Прицел | мышь |
| Удар | ЛКМ (в такт пульса — усиленный) |
| Рывок | Пробел |
| Взаимодействие | E |
| Перезарядка | R |
| Исцеление | Q |
| Оружие | 1 / 2 / 3 |
| Журнал | J |
| Карта | M |
| Пауза | Esc |

Геймпад: левый стик — движение, правый — прицел, RT/A — удар,
B — рывок, Y — взаимодействие, Start — пауза.

## Что реализовано

- **6 зон:** Мастерская, Верхний Город, Библиотека, Больница, Фабрика Кукол, Ядро.
- **3 оружия:** нож (режет верёвки, бонус со спины), пистолет (кнопки и патроны), коса (баррикады, широкий замах).
- **4 врага + босс:** Ползун, Плакальщик, Ткач, Страж, Первый Кукольник (3 фазы).
- **Душа:** сила, трата, потеря при уроне, свеча, эхо смерти.
- **Пульс:** 62–132 BPM, окно 0.13 c, удар в ритме не тратит Душу и бьёт сильнее.
- **Свет:** синий фонарь, свеча, тьма; медитация, чекпоинты, топливо фонарей.
- **Тела:** Фарфор, Дерево, Плоть — разные HP/Душа/скорость/рывок.
- **Память:** 12 осколков, журнал, разблокировка тел, алтарь.
- **Сохранение:** JSON, чекпоинты, потерянная Душа, посещённые зоны.
- **Интерфейс:** HUD, пауза, журнал, карта, выбор тела, настройки, смерть, финал.
- **Процедурные графика и звук:** 128 спрайтов, синтезированные SFX/эмбиент, 2D Light.

## Технологии

- Unity 6000.5.8f1, URP 17.6, 2D Renderer, Input System 1.20.
- C#, ScriptableObject, JSON-сохранения, uGUI, Tilemap, 2D Lights.
- Все ассеты генерируются скриптами `tools/art_gen.py`, `tools/map_gen.py`, `tools/audio` (C#).

## Открыть в Unity

1. Откройте папку проекта в Unity Hub (Unity 6000.5.8f1).
2. Сцена входа: `Assets/PUPPET/Scenes/MainMenu.unity`.
3. Игровые сцены: `Workshop`, `UpperCity`, `Library`, `Hospital`, `Factory`, `Core`.
4. Меню `PUPPET → Generate Content` пересобирает ArtLibrary, данные и сцены.
5. Меню `PUPPET → Build Windows` собирает `Build/PUPPET_UndergroundWhisper.exe`.

## Ограничения вертикального среза

- 6 зон используют общий набор механик и процедурные тайлсеты; уникальные сет-пиcы каждой зоны — следующий этап.
- Тела-классы и осколки памяти реализованы в базовом виде (без отдельного древа апгрейдов).
- Нет редактора ребинда клавиш и локализации, кроме русского.
- Босс один; полноценная метроидвания с возвратами и ключами — задел на основную разработку.
